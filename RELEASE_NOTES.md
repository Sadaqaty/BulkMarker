# Bulk Video Watermarker v1.0.0 - Linux Release

## What's New

🎬 **Bulk Processing**: Process hundreds of videos simultaneously with intelligent batch processing and real-time progress tracking.

🎨 **Multiple Overlay Types**: Support for images, videos, and text overlays with full customization options including scaling, positioning, opacity, and rotation.

⚡ **Smart Positioning**: Precise overlay placement with 9 anchor points (left-top, center, right-bottom, etc.) for perfect alignment.

💾 **Preset Management**: Save and reuse overlay configurations for different platforms like YouTube Shorts, TikTok, and Instagram Reels.

🚀 **Cross-Platform**: Native executables available for Linux (AppImage), Windows, and macOS.

## Key Features

- Faceless channel management support
- Agency workflow optimization
- Brand protection with professional watermarks
- Modern, intuitive GUI built with PySide6
- MoviePy integration for high-quality video processing

## System Requirements

- Linux distribution with glibc 2.17+
- FFmpeg installed for video processing
- No Python installation required (standalone AppImage)
